# 形迹：照片转人形 Pictogram

中文浏览器工具。照片只在浏览器内处理，无需账户、API 密钥、数据库或付费 AI。

## 本地运行

1. 安装 Node.js 18 或更新版本（推荐当前 LTS）：https://nodejs.org/ 。安装后重新打开终端。
2. 在此仓库目录打开终端，执行 `npm start`（无需 npm install，没有服务端依赖）。
3. 在同一台电脑浏览器打开 http://localhost:3000 。停止时在终端按 Ctrl+C。
4. 若端口被占用，macOS/Linux 使用 `PORT=3001 npm start`；Windows PowerShell 使用 `$env:PORT=3001; npm start`。

也可安装 Python 3 后，在仓库执行 `python -m http.server 3000`，再打开同一地址。不要直接双击 HTML，模块脚本需要 HTTP 服务。

## 使用

上传单人全身 JPG/PNG/WebP，点击自动识别，检查并拖动左侧编号圆点。调整头部、线条粗细和颜色，导出透明 PNG 或 SVG。输入图片最大 30MB，工作画布最长边为 1600px，导出使用工作画布尺寸。SVG 可继续在矢量编辑器调整。

自动识别使用 MediaPipe Pose Landmarker Lite（CPU），第一次联网从 cdn.jsdelivr.net 加载版本 0.10.32 运行库及 WASM，从 storage.googleapis.com 加载模型。浏览器完成推理，不发送照片。缓存由浏览器管理；自动识别并不保证离线可用，下载可能受网络限制。当前云端实测：运行库地址可达，官方模型域名 storage.googleapis.com 被云环境策略拒绝（403），所以尚未验证自动识别成功。模型功能需在可访问以上域名的浏览器验证。模型无法加载、未检测到人体或主要关节置信度过低时会明确报错，不填入预设姿势。

**无需网络的手动模式**：上传照片后，选择“手动标注关节”，按提示依次点击头中心、左肩、右肩、左肘、右肘、左腕、右腕、左髋、右髋、左膝、右膝、左踝、右踝、颈部中心（左右以人物自身为准）。完成全部 14 点后出现小人，可拖动修正；标注过程中可撤销上一个点。重新标注会提示清除已有结果。

原图与预览均保留照片宽高比；圆头、几何躯干、圆端粗线四肢用于图形化表达，不属于实际安全标识合规产品。二维姿态存在遮挡、侧身及多人误识别限制。

## 开发与验证

原生 ES modules + CSS + SVG，无构建步骤。`npm test` 运行几何导出测试。`npm run dev` 启动静态服务器。服务器不接收文件上传，只提供四个前端资源；不应作为公网生产服务器。
